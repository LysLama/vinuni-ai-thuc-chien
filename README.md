## 🚀 4. Hướng Dẫn Khởi Động Nền Tảng Luyện Thi

### Cách 1: Nền tảng Web Application Hiện Đại (Khuyến nghị số 1)
Chạy lệnh khởi động máy chủ FastAPI:
```powershell
cd D:\proj
python server.py
```
Sau đó mở trình duyệt tại: **`http://localhost:8000`**

*Đặc điểm thiết kế (Chuẩn kỹ nghệ Impeccable - Operate Mode):*
- **Giao diện phòng thi chuẩn mực:** Không AI slop, không viền màu trang trí thừa thãi, không gradient chữ, không card lặp vô nghĩa.
- **Đồng hồ đếm ngược 90 phút:** Tự động lưu trạng thái vào `localStorage` (không lo mất bài khi F5 tải lại trang).
- **Phím tắt nhanh:** Phím `1, 2, 3, 4` hoặc `A, B, C, D` để chọn đáp án; `N` (Next), `P` (Prev), `F` (Flag đánh dấu cờ).
- **Bảng điều hướng câu hỏi (Palette Grid):** Trạng thái trực quan (Đã làm, Chưa làm, Cắm cờ xem lại).
- **Hỗ trợ công thức Toán & Code:** Tích hợp KaTeX render trực tiếp các công thức ma trận, đạo hàm và Prism.js highlight mã nguồn Python.
- **Tính năng In ấn / Xuất PDF:** Hỗ trợ phím `@media print` giúp xuất đề thi ra bản in sạch sẽ.

### Cách 2: Ứng dụng Streamlit
```powershell
cd D:\proj
streamlit run app.py
```

### Cách 3: Ứng dụng Dòng lệnh Console (CLI)
```powershell

```
